# EGISSO to GIS ECP Converter (`egisso-to-ecp`)

Профессиональный инструмент (GUI + CLI) для миграции исторических данных (2023 — декабрь 2026) из форматов ЕГИССО в формат пакета сведений о решениях ЛК РСМСЗ / ГИС ЕЦП.

---

## Архитектура проекта

Проект спроектирован по канонической **чистой (гексагональной) архитектуре**:
- **`domain`**: Чистая бизнес-логика. Модели данных (Pydantic v2), нормализаторы (СНИЛС, даты, ОКТМО), валидаторы ФЛК (форматно-логический контроль), исключения.
- **`application`**: Сценарии использования (Use Cases), конвейер обработки (`Pipeline`), логика разбиения по месяцам (`Splitter`) и контроль лимита размера пакета (19 МБ).
- **`infrastructure`**: Чтение старых реестров (Excel `openpyxl`), рекурсивное/линейное сканирование каталогов с извлечением даты из путей, генерация иерархических CSV (`utf-8-sig`) и XLSX, выгрузка отчёта об ошибках (`errors_report.xlsx`).
- **`presentation`**:
  - `gui`: Современный графический интерфейс в нативном стиле Windows 11 (PySide6) с фоновой асинхронной обработкой в `QThread`.
  - `cli`: Консольный интерфейс на `Typer` с цветными прогресс-барами `Rich`.

## Возможности

1. **Гибкое сканирование каталогов**:
   - Чекбокс **«Рекурсивный поиск»** (по умолчанию включён).
   - Извлечение года/месяца как из данных файла, так и из названий папок и файлов (регулярные выражения для путей `2024\05`, `2024_05_стипендии.xlsx`).
2. **Разбиение по месяцам**:
   - Чекбокс **«Разбивать по месяцам»** (по умолчанию включён). Все меры за один календарный месяц собираются в единый помесячный пакет.
3. **Выбор формата выгрузки**:
   - Чекбоксы **«CSV (ГИС ЕЦП)»** (по умолчанию включён) и **«Excel (.xlsx)»**.
   - Автоматическое разделение по отдельным папкам: `output/csv/` и `output/xlsx/`.
   - Иерархическая выгрузка 107 столбцов по спецификации ГИС ЕЦП (базовая строка пакета, родительская строка `Решение` с `ТипДокумента = 3` и дочерние строки `ПериодыНазначения` / `СвязанноеЛицо`).
4. **Строгий форматно-логический контроль (ФЛК)**:
   - Проверка контрольного числа СНИЛС по официальному алгоритму ПФР (включая числовые ячейки Excel).
   - Нормализация кодов ОКТМО (удаление точек и спецсимволов) и вычисление `КодРегиона`.
   - Автоматическая трансляция кодов единиц измерения (ОКЕИ `383` для рублей).
   - Преобразование сериальных дат Excel в ISO `YYYY-MM-DD`.
   - Булевы флаги `true`/`false` по спецификации ЕЦП.
   - Установка признака исторических данных (`ПризнакИсторическихДанных = true`).
5. **Контроль размера файлов**:
   - Автоматическое секционирование пакетов при приближении к лимиту 18.5 МБ (ограничение платформы 20 МБ).

## Готовая сборка для Windows (без установки Python)

Для запуска программы на компьютерах без установленного Python предназначена переносимая (portable) сборка в одном исполняемом файле:

- Файл программы: `dist/EGISSO_to_ECP.exe`
- Текст лицензии: `dist/LICENSE.txt`

Просто скопируйте `EGISSO_to_ECP.exe` (и при желании `LICENSE.txt`) в любую папку на ПК с Windows 10/11 и запустите двойным щелчком мыши. Готовые пакеты по умолчанию сохраняются в подпапку `output/` рядом с `.exe`.

### Самостоятельная сборка `.exe` из исходного кода
```bash
uv pip install -e ".[dev]"
python scripts/build_exe.py
```
После завершения в каталоге `dist/` появятся `EGISSO_to_ECP.exe` и `LICENSE.txt`.

## Запуск из исходного кода

### Установка зависимостей с помощью `uv`
```bash
uv pip install -e ".[dev]"
```

### Запуск GUI
```bash
uv run egisso-to-ecp-gui
# или напрямую:
uv run python -m egisso_to_ecp.presentation.gui.main
```

### Запуск CLI
```bash
uv run egisso-to-ecp --help
uv run egisso-to-ecp convert --input "C:/path/to/egisso_files" --output "C:/path/to/output" --split-months --csv --xlsx --provider 430746
```

### Запуск тестов и линтеров
```bash
uv run pytest
uv run ruff check .
uv run mypy src
```
